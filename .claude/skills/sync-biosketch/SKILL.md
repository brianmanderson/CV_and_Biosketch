# Sync biosketch with CV

**Report-only skill.** Compare and report discrepancies; Brian decides what to
change (edits then follow the same formatting-preservation rules as
`/update-cv`, applied to `Biosketch_BMA.docx`).

Sources: `Clincal_CV/BMAnderson CV.docx` (CV, source of truth for facts) vs
`Biosketch_BMA.docx` (NIH OMB-format biosketch). Read both with `python-docx`.
See `CLAUDE.md` for both documents' structures.

Also relevant: `Anderson_CommonFormBiosketch.pdf` is generated by **SciENcv**
(from ORCID), not from the .docx — discrepancies found there can only be fixed
in SciENcv/ORCID, so list them separately as "fix in SciENcv".

## Checks

1. **Positions and appointments** — Biosketch section B ("Positions and
   Scientific Appointments" + "Positions and Employment") vs the CV header,
   Professional Service Activities, and Research Experience. Every position
   change on the CV (new role, ended role, new committee) should be reflected;
   date ranges must agree (watch for stale "Present" on ended roles). Check the
   POSITION TITLE header field and education table too.
2. **Honors/Awards/Grants** — CV "Honors and Awards" + "Grants and Fellowships"
   vs biosketch "Honors/Awards/Grants" list. New CV awards/grants are strong
   candidates to add; year mismatches are errors.
3. **Invited Talks** — biosketch mirrors the CV's Invited Talks list; new CV
   talks should normally be added here.
4. **Selected products (section C)** — the biosketch lists only a **handful of
   selected products; a CV publication missing here is a choice, not an
   error.** Only flag: (a) new first-author or otherwise clearly major papers
   Brian may want to swap in, and (b) products that look stale relative to his
   current research focus. Never call the product list "incomplete."
5. **Common-form compliance** — sanity checks on the .docx: sections A/B/C
   present and in order; education table intact; the whole document renders at
   ≤5 pages (the form's stated limit); date-tab alignment consistent within
   lists; entries newest-first; Brian's name bold in product citations.
6. **Narrative drift** — flag (don't rewrite) Personal Statement /
   Contributions to Science claims that have gone stale, e.g. paper counts
   ("over 20 peer-reviewed papers"), current-institution mentions, or "ongoing"
   work that has since published.

## Report format

- **Discrepancies (fix in Biosketch_BMA.docx)** — factual mismatches, each with
  CV value vs biosketch value and location.
- **Suggestions** — optional additions (new talks, awards, product swaps).
- **Fix in SciENcv/ORCID** — issues that live in the common-form PDF pipeline.
- **Compliance notes** — form-structure problems, if any.

End by asking which changes Brian wants applied. Do not edit any document in
this skill.
