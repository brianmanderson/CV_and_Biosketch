# CV and Biosketch

Personal document storage for Brian Anderson's curriculum vitae and biosketch files. This is not a code project — the repo exists to version-control the source documents (Word) and their PDF exports.

Contents:

- `BMAnderson CV.docx`, `Biosketch_BMA.docx`, `Updated_Biosketch_BMA.docx` — CV and biosketch drafts
- `Anderson_CommonFormBiosketch.pdf` — common-form biosketch export
- `Clincal_CV/` — clinical CV versions (including a copy with notes), PDF exports, and a Deep Learning Portfolio document

No build steps, dependencies, or usage — open the files directly in Word or a PDF reader.
